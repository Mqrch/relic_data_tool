## How to use
1. Download [the latest version](https://github.com/Mqrch/relic_data_tool/releases/latest).
2. Extract the zip file and run the .exe file.

## Relic Inventory
If you have Aleca, relic inventory will automatically be loaded.
If your data is anywhere other than the default path, change the path in settings.json.

## Building from source
1. Clone the repository: `git clone https://github.com/Mqrch/relic_data_tool.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run main.py or compile the executable: `pyinstaller --onefile --windowed main.py`
